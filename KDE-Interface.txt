# AI Assistant Interface for KDE Plasma 6 - Project Document

## Project Overview

This document outlines the development of a native KDE Plasma 6 interface for interacting with AI models through the UnicornCommander ecosystem. The interface provides a seamless, system-level AI assistant experience with advanced memory features, agent capabilities, and multiple backend options including hardware acceleration.

## 1. System Architecture

```
┌─────────────────────────────────────┐
│        UnicornCommander System      │
├─────────────────┬───────────────────┤
│ KDE AI Interface│  Backend Services │
│ ┌─────────────┐ │ ┌───────────────┐ │
│ │     UI      │ │ │  MCP Servers  │ │
│ │  Components ├─┼─►  (System      │ │
│ └─────────────┘ │ │   Control)    │ │
│ ┌─────────────┐ │ └───────────────┘ │
│ │  Memory     │ │ ┌───────────────┐ │
│ │  System     ├─┼─►  Quark Server │ │
│ └─────────────┘ │ │  (AMD Accel)  │ │
│ ┌─────────────┐ │ └───────────────┘ │
│ │  Agent      │ │ ┌───────────────┐ │
│ │  System     ├─┼─► AI Models     │ │
│ └─────────────┘ │ │ (Local/Remote)│ │
└─────────────────┴───────────────────┘
```

### Components:
- **KDE AI Interface**: PyQt6-based native KDE Plasma 6 application 
- **MCP Servers**: System control capabilities for desktop integration
- **Quark Server**: AMD Ryzen AI hardware acceleration
- **Memory System**: Vector databases for short and long-term memory
- **Agent System**: Specialized agents for different tasks

### Communication Flow
1. User input captured through interface
2. Backend manager routes request to appropriate backend
3. For MCP-enabled agents, request routed through MCP servers
4. Memory system enhances prompt with relevant context
5. Response streamed back to user interface
6. Context maintained in memory system

### Configuration Options
- OpenAI API settings (key, model, parameters)
- Ollama server configuration (URL, model selection)
- AMD Ryzen AI options (model selection, performance settings)
- Memory system settings (vector database, embedding model)

### MCP Client Interface

```python
class MCPCoordinatorClient(QObject):
    """Client for interacting with the MCP Central Coordinator and its servers"""
    
    # Signals
    operation_started = pyqtSignal()
    operation_result = pyqtSignal(dict)
    operation_error = pyqtSignal(str)
    
    async def query_krunner(self, query):
        """Query KRunner for the given search term"""
        return await self.execute_operation("kde", "/api/krunner/query", "POST", {"query": query})
    
    async def execute_code(self, code, language="python"):
        """Execute code in the specified language"""
        return await self.execute_operation("code", "/api/execute", "POST", 
                                           {"code": code, "language": language})
```

## 9. Hardware Acceleration Setup

### AMD Ryzen AI Setup (Ubuntu 24.10)

1. **Install ROCm Components**:
   ```bash
   # Update system
   sudo apt update && sudo apt upgrade -y
   
   # Add ROCm repository
   wget -qO - http://repo.radeon.com/rocm/rocm.gpg.key | sudo apt-key add -
   echo 'deb [arch=amd64] http://repo.radeon.com/rocm/apt/debian/ noble main' | sudo tee /etc/apt/sources.list.d/rocm.list
   
   # Install ROCm components
   sudo apt update
   sudo apt install -y rocm-smi rocminfo rocm-cmake
   ```

2. **Install XDNA Driver**:
   ```bash
   sudo apt install -y amdxdna-dkms
   sudo modprobe amdxdna
   ```

3. **Install XRT (Xilinx Runtime)**:
   ```bash
   # XRT package for Ubuntu 24.10
   sudo apt install -y xrt
   
   # Set environment variables
   echo 'export XILINX_XRT=/opt/xilinx/xrt' | sudo tee -a /etc/environment
   ```

4. **Download and Install AMD Ryzen AI Software Stack**:
   ```bash
   # Download from AMD's official website and install
   # Specific commands will depend on AMD's latest package format
   
   # Verify installation
   python -c "import onnxruntime as ort; print(ort.get_available_providers())"
   # Should show 'VitisAIExecutionProvider' in the list
   ```

5. **Verify Hardware Acceleration**:
   ```bash
   # Check XDNA device
   ls -la /dev/amdxdna*
   
   # Check ROCm installation
   rocminfo
   ```

### Performance Expectations:
- **DeepSeek 6.7B**: 15-25 tokens/second with NPU acceleration
- **DeepSeek 1.3B**: 40-60 tokens/second with NPU acceleration
- **CPU-only fallback**: Still functional but with reduced performance

## 13. Setup for Ubuntu 24.10 with KDE Plasma 6

1. **Install Dependencies**:
   ```bash
   sudo apt update
   sudo apt install -y python3-pyqt6 python3-pyqt6.qtwebengine python3-pip python3-venv
   sudo apt install -y libqt6sql6-psql redis-server postgresql
   ```

2. **Create Python Virtual Environment**:
   ```bash
   python3 -m venv ~/unicorn-env
   source ~/unicorn-env/bin/activate
   pip install -r requirements.txt
   ```

3. **Set Up Databases**:
   ```bash
   # PostgreSQL setup
   sudo -u postgres createdb kde_ai_interface
   sudo -u postgres createuser -P $USER
   sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE kde_ai_interface TO $USER;"
   
   # Start Redis
   sudo systemctl start redis
   ```

4. **Run the Application**:
   ```bash
   # Main unified interface
   ./run_unified_ai_gui.sh
   
   # Or hardware-accelerated version if AMD Ryzen AI is available
   ./run_ryzen_ai_model.py
   ```
